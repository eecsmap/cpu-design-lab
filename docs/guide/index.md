# Lab guide

A path through the five Sodor cores, in the order that makes each one explain
the next. Every lab ends in something you can measure rather than something you
merely read.

Do them in order. The 5-stage forwarding experiment is the payoff, but it only
means anything once you have read the 1-stage and understand why a pipeline
register needs a valid bit.

Set `$LAB` to your clone of this repo before running any command here:

```bash
export LAB=~/github/cpu-design-lab
```
